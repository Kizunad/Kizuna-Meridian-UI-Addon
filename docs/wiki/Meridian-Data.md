# 经脉数据页

状态：已实现。经脉窗口顶部有「经脉」「数据」两个页签，「数据」页把身体快照里的经脉真元整理成整体数字、相态柱、元素圆环和逐条明细。只读，不发任何请求。

## 打开方式

按 `I` → 修炼 → 经脉，点窗口左上的「数据」页签；点「经脉」回到模型。窗口右上 `(i)` 的说明里也写了这一页。

## 页面内容

| 区域 | 内容 |
|---|---|
| 整体 | 经脉真元（内腔 + 外壁）；内腔、外壁各自的「现有 / 可装 元（占用%）」和占用条；按相态的柱状图；器官缓存与在途真元 |
| 元素构成 | 经脉真元按属性分的圆环，中心写最多的属性；右侧图例列出每种属性的元数和占比 |
| 明细表 | 每条经脉一行：名称、开拓阶段、内腔、外壁、平均密度、主属性 |
| 展开一行 | 点一行展开：状态、开拓与进度、吞吐、承受度、疲劳、两个账户、相态构成、属性构成条；再点收起 |

行顺序沿用身体构型里的经脉顺序；构型里有、状态还没同步的经脉不进表（检视窗口会报缺失）。展开状态在快照刷新和整表重建后保留。

## 数据与换算

只读客户端已有的身体快照，不增加任何同步字段。换算与检视窗口用同一套函数（`QiDisplay`），两边数字对得上：

- 元数：账户里每笔真元的 `amount` 相加。
- 可装：`QiDisplay.displayedCapacity(体积, 账户)`，按账户当前平均密度换算，所以真元变密时可装会跟着变大。整体卡的可装是各条经脉的可装相加，不是全身平均密度乘总体积。
- 占用：按体积，已占体积（元数 ÷ 密度）之和除以内腔或外壁体积之和。
- 平均密度：内腔元数除以内腔已占体积；空经脉记 0。
- 相态：按 `QiDensity.phase` 的密度区间归类，内腔外壁合计，从稀到密排列。
- 属性：内腔外壁合计，元数多的在前，同量时按属性 ID 排；没有译名的附属属性直接写属性 ID。
- 器官缓存含加工中的原料，与 `QiDisplay.total` 口径一致；在途是已离开发出端、还没到目的经脉的真元。器官和在途不算进经脉真元。

## 悬停说明

整体卡的各项、相态柱、元素圆环与图例、表头每一列、每行的标题条都有悬停说明，写这个数字是什么、怎么算的；行的说明给出完整的内腔、外壁数值和「点击展开 / 收起」。窄窗下被截短的文字以悬停说明里的完整数值为准。

## 没开脉时

一条经脉都没开拓时，明细表顶上有一行淡色提示，指到「经脉」页去开拓；开拓第一条后提示自动消失。快照里还没有经脉时提示改为没有数据。

## 窗口缩放

- 默认尺寸（560×450）：两张卡并排，表格在下，外层不出滚动条，与初版排布一致。
- 宽度放不下两张卡并排（内容宽 < 406）时，元素卡移到整体卡下方，两张卡同宽。
- 高度放不下两张卡 + 表头 + 4 行时，整页套一层滚动并让出滚动条宽度；表格本身仍可单独滚动。
- 列宽不够时列名和数值截短，账户列退成只写现有元数；完整数值看悬停说明。展开行的说明文字不折行，最小窗口下右侧会被窗口边缘裁掉。

## 语言

界面文字在 `assets/meridian_ui/lang/{zh_cn,en_us}.json` 的 `meridian_ui.data.*` 下，两份键集合一致。经脉状态、开拓阶段、相态的中文叫法与检视、吐纳窗口一致，由单测对照。经脉名称来自宿主下发的身体构型，不随客户端语言切换；检视、吐纳窗口仍只有中文。
